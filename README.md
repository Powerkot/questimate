# QUESTIMATE

Fantasy planning poker. Estimate together, reveal together.

**[questimate.ru](https://questimate.ru)**

Sit at the table, pick a card, keep it face-down until the host opens the round. A raid-style chat, a snowball, and a cast of original characters for every size on the scale: `xs s m l xl XXL ? ☕`.

## Run

```bash
npm install
npm run dev
```

Open the app, create a room or join with a 5-character code. The host posts a task; everyone votes in secret; then reveal, talk through the farthest estimates, and save the result.

## Stack

TanStack Start, React, Tailwind, Postgres (Neon in production, PGLite locally).
