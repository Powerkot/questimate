# Questimate 2.0.0

Версия собирает выбранные пользователем решения из двух референсов Arena AI.

- Главная: веер XS–XXL.
- Комната: адаптивный овальный стол, аватары, пунктир ожидания, карты с небольшими наклонами и анимацией появления.
- Голосование: простые карты с подписями, закреплённая рука с подъёмом при наведении/фокусе; кнопка раскрытия в самой нижней панели ведущего.
- Демо: голоса ботов появляются постепенно; песочница по-прежнему изолирована во вкладке.
- Результат: распределение голосов, сохранённые медиана/мода/диапазон/согласие, отдельная анимация принятого итога с переворотом, бликом, наклоном и надписями поверх персонажа.
- Журнал: все задания, предстоящие, завершённые; добавление в очередь, запуск и удаление из очереди ведущим. Завершёнными считаются принятые результаты, а не просто раскрытые голоса. Подробности прежней истории сохранены.
- Ведущий может передать роль или удалить участника с подтверждением. Сервер проверяет полномочия и блокирует повторный вход удалённой браузерной идентичности в эту комнату.
- Сокращённое движение, клавиатурный выбор, RU/EN, мобильная safe area.

## Проверка

- TypeScript и точечный ESLint.
- 38 poker-тестов: очередь → голосование → принятый итог, запрет замены активной задачи, права ведущего, передача роли, исключение/повторный вход, постепенное демо-голосование.
- Production-сборка.
- Браузер: мобильный 390×844 и настольный 1440×1000; выбор → раскрытие → принятие → итоговая карта → закрытие; журнал → добавление → запуск задачи; серверная очередь и восстановление сессии после reload.
