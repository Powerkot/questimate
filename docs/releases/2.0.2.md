# Questimate 2.0.2

По второму референсу Arena AI: корона ведущего по центру над аватаром, отдельная отметка «ВЫ», имя с выразительной засечковой типографикой, шуточная должность курсивом и статус разрядкой. Должности локализованы RU/EN и стабильны для идентичности игрока; роль ведущего всегда «Хранитель стола».

Карточка задачи и форма до начала голосования оформлены как светлая страница книги: пергамент, затемнённые края, тёмные заголовки, курсивное описание, восковая печать. Отдельный этап ожидания не добавлялся; правила голосования прежние.

Высота настольного стола скорректирована под дополнительную строку игрока. Проверки: TypeScript, точечный ESLint, production-сборка, настольный 1440×1000 и мобильный 390×844, отсутствие перекрытия нижнего участника рукой и горизонтального переполнения.

Откат: предыдущий образ/исходники 2.0.1; база 1.0 сохраняется, см. 2.0.0.md. Серверная логика и данные не менялись.
