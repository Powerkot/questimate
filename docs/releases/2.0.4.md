# Questimate 2.0.4

Пятый референс Arena: стол с устойчивыми пропорциями, игроки на внешнем овале, карты — напротив них на внутреннем. Координаты карты больше не зависят от высоты имени, должности или статуса. При раскрытии карта остаётся на месте, меняется только лицевая сторона; рубашки и лица сохраняют одинаковые размеры. На мобильном внутренний овал сужен, чтобы карты не пересекались с подписями. Пустые места без голоса не рисуют карты.

Стол покрыт новой текстурой тёмного дуба (1536×1024, WebP ~301 KiB), с мягким тёплым освещением, золотой инкрустацией и объёмным бортом. Генерация встроенным imagegen; исходный prompt и референс сохранены отдельно в references/v2/arena-05. Пропорции сцены сохраняются при изменении высоты окна: уменьшается вся композиция, а не только стол по вертикали. В коротком окне доступна обычная прокрутка; панель раскрытия остаётся в фиксированной руке.

Проверки: typecheck, ESLint компонента, production build; браузер 1440×1000 и 390×844, голосование, раскрытие, переключение «Стол / Карты», отсутствие горизонтального переполнения. Серверная логика и база данных не менялись.
