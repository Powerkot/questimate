# Questimate 2.0.5

После раскрытия одна общая панель объединяет управление раундом, распределение всех восьми оценок, согласие команды, моду, медиану и крайние оценки. Ведущий выбирает итог кликом по столбцу этого же распределения; выбор подсвечивается и явно подписывается. Повторная диаграмма удалена. Подробный разбор и комментарий к решению раскрываются внутри общей панели.

Для участников без прав ведущего распределение остаётся доступным для чтения. В режиме презентации показана одна информационная панель без выбора и управляющих действий. При отсутствии голосов сохраняется возможность вручную выбрать итог. Серверная логика, сохранение решения/комментария и база не изменялись.

Проверки: typecheck, ESLint изменённых компонентов, production build; браузер 1440×1000 и 390×844, одна диаграмма, выбор M при большинстве S, раскрытие подробностей/комментария, утверждение M с комментарием, отсутствие горизонтального переполнения и ошибок консоли.

Откат: v2.0.4 / questimate-web:1d21bf1; 1.0 сохранена.
